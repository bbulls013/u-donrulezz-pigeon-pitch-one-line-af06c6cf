A deterministic program entry for the make.fun bounty
[u-donrulezz-pigeon-pitch-one-line-af06c6cf](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf).

`main.py` writes one English line (at most 200 characters) to
`/output/entry.txt`: the elevator pitch a city pigeon gives investors
for its startup.

Run it with:

```sh
python3 main.py
```

Set `OUTPUT_PATH` to write somewhere else for local testing.

The program is deterministic: every run writes the same bytes.
No network, no inputs, no dependencies beyond the Python standard library.
